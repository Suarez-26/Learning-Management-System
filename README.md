# 📚Learning Management System

La Institución educativa ABC, en aras de mejorar la calidad de educación que imparte, ha decidido implementar una herramienta que les permita a la comunidad educativa (estudiantes, docentes y administrativos) acceder a la información de forma práctica y potenciar la experiencia de aprendizaje.



## 🌐Demo en vivo

[Ver  Learning Management System en vivo](https://sunny-meringue-202d8e.netlify.app/)



## Caracteristicas Principales

- 🏠**Exploracion de cursos** (muestra todos los cursos registrados )
- 🔐**Autenticación de usuarios**( validacion del admin)
- **Dashboard principal**(Pagina principal )
- **Panel de docentes** (Sistema CRUD de docentes)
- **Panel de cursos, modulos y lecciones** (Sistema CRUD de cursos, modulos y lecciones
- **Diseño responsive** (completamente adaptado a móviles hasta 400px)
- 💾 **Persistencia de datos** con JSON Server
- 🧠 **Interfaz moderna y accesible**, basada en tipografías Poppins y Playfair Display

## Instalación y ejecución



### 1️⃣ Clonar el repositorio

```
git clone https://github.com/tuusuario/hotel-reservas.git
cd hotel-reservas
```

### 2️⃣ Instalar JSON Server

```
npm install -g json-server
```

### 3️⃣ Ejecutar el servidor de datos

```
json-server --watch db.json --port 3000
```

### 4️⃣ Abrir el proyecto

Abre index.html en tu navegador o usa una extensión de servidor local como Live Server en Visual Studio Code.
